🎨 Game Editor
How to use the Game Editor

Concept

A custom game is a sequence of states. Each state defines what the pucks do (light up, play a sound) and what triggers the next state (a button press or a timeout).

Quick Start

  • Click + Add State to create your first state
  • Add Puck Actions to define which pucks light up with which effect and color
  • Add Transitions to define what happens next (button press or timeout)
  • Create more states and link them together via transitions
  • Click Save to Coordinator, then Play to test

Available Effects

  • Static — solid color
  • Breathe — pulsing glow (fast or slow)
  • Single/Double Chase — spinning LED animation
  • Countdown — visual countdown timer (set duration in ms)
  • Status — small status indicator dot

Current Limitations

  • Max 30 states per game, 12 actions per state, 4 transitions per state
  • No scoring, counters or variables — this is a pure state machine
  • No loops — to repeat, point the last transition back to an earlier state
  • Only one custom game can be saved on the coordinator at a time
  • Puck numbers are fixed slots (P1–P8), not dynamic
